# AI-Assisted Testing Guidelines

AI can accelerate scenario brainstorming, boilerplate, log summarization, and review preparation. It does not own release decisions or replace product/domain knowledge.

- Never send credentials, patient information, customer data, or proprietary logs to unapproved tools.
- Verify generated tests against requirements and system behavior.
- Require normal code review, static checks, and deterministic execution.
- Prefer AI suggestions that improve testability or expose a missing risk over generating more shallow test cases.
- Record material AI assistance when organizational policy requires it.
